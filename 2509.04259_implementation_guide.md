# Implementation Guide from Paper 2509.04259v1

Source paper: "RL'S RAZOR: WHY ONLINE REINFORCEMENT LEARNING FORGETS LESS" (arXiv:2509.04259v1, Sep 4, 2025).

## 1) Dataset-wise implementation procedure

### A. LLM - Math Reasoning
- Base model: `Qwen2.5 3B-Instruct`.
- Training dataset: Open-Reasoner-Zero math questions.
- SFT data construction:
  - The dataset had final answers but not reasoning chains.
  - Authors queried DeepSeek R1, sampled up to 16 responses per prompt, and kept one response whose final answer matched ground truth.
  - This produced valid annotations for about 96% of examples.
- RL training:
  - Method: GRPO (unless otherwise stated in the paper).
  - Reward: binary success indicator.
  - Explicit KL regularization: none (`KL reg = 0` in Table 2).
- New-task evaluation:
  - Compare final answer to ground truth (ignore intermediate reasoning text).
- Forgetting evaluation:
  - Evaluate on unrelated prior benchmarks with LM Evaluation Harness.
  - LLM prior-task benchmarks listed: HellaSwag, TruthfulQA, MMLU, IFEval, Winogrande, HumanEval.
- Trade-off curve construction:
  1. Sweep hyperparameters.
  2. Evaluate new-task and prior-task metrics.
  3. Keep points within 2 accuracy points of the Pareto frontier.
  4. Fit an exponential curve to filtered points.

### B. LLM - Science Q&A
- Base model: `Qwen2.5 3B-Instruct`.
- Training dataset: Chemistry L-3 subset of SciKnowEval.
- SFT data construction:
  - Same approach as Math, but with GPT-4o for reasoning-chain annotation.
  - Reported valid annotations for the full dataset.
- RL training:
  - GRPO with binary success reward, no explicit KL regularization.
- New-task evaluation:
  - Final answer exact-match style scoring (reasoning chain ignored).
- Forgetting evaluation and Pareto protocol:
  - Same as Math.

### C. LLM - Tool Use
- Base model: `Qwen2.5 3B-Instruct`.
- Training dataset: ToolAlpaca.
- RL and SFT setup:
  - Included in the same LLM protocol/hyperparameter sweep as Math and Science.
- New-task evaluation:
  - Extract API calls from model output.
  - Match extracted calls to ground-truth API calls with regex rules.
- Forgetting evaluation and Pareto protocol:
  - Same as other LLM tasks.

### D. Robotics - Pick and Place (SimplerEnv)
- Base model: `OpenVLA-7B`.
- Environment: SimplerEnv.
- Fine-tuning task: pick-and-place (grasp and lift a can).
- Forgetting measured on: distinct drawer open/close manipulation tasks.
- Data collection:
  - Training positions sampled on a `10 x 10` grid.
  - Reported ranges: `obj-init-x in [-0.35, -0.12]` and `obj-init-y in [-0.02, 0.42]`.
  - Evaluation uses 100 uniformly sampled random object locations in this area.
- SFT data generation:
  - For each grid point, collect 10 successful RT-1 trajectories and keep successful ones.
- RL training:
  - Algorithm: REINFORCE with reward-normalization baseline.
  - Reward: binary success.
  - No explicit KL regularization.
  - Per iteration: collect 5 trajectories per grid point.
- Pareto curve protocol:
  - Same procedure as LLM experiments.

### E. MNIST Controlled Study (ParityMNIST vs FashionMNIST)
- Model: 3-layer MLP.
  - Input: 785 dims (`28 x 28` flattened image + binary task indicator).
  - Hidden layers: 512, 256.
  - Output: 10 classes.
- Pretraining:
  - Joint on ParityMNIST and FashionMNIST.
  - 500 samples from each dataset.
  - ParityMNIST pretraining labels are uniformly sampled among labels with correct parity.
- Fine-tuning methods compared:
  1. GRPO.
  2. GRPO + KL regularization (coefficient 0.1).
  3. SFT-1 mapping: all even -> 0, all odd -> 1.
  4. SFT-2 mapping: even -> {0, 4}, odd -> {1, 5} (randomized within sets).
  5. SFT with oracle distribution (minimum-KL distribution under correctness constraint).

## 2) Hyperparameters used (by dataset/model)

### A. LLM experiments (Math, Science, Tool Use) - Qwen2.5 3B-Instruct

#### SFT / SIMPO column (Table 2)
- Learning rate sweep: `{1e-5, 3e-5, 5e-5, 7e-5, 9e-5}`
- Optimizer: `AdamW`
- LR scheduler sweep: `{constant with warmup, cosine with warmup}`
- Warmup steps: `50`
- Epochs sweep: `{1, 2}`
- Batch size sweep: `{16, 32, 64, 128}`
- Max grad norm: `1`
- Precision: `bfloat16 = True`
- Weight decay: `0`

#### RL (GRPO) column (Table 2)
- Learning rate sweep: `{1e-5, 2e-5, 3e-5, 4e-5, 5e-5}`
- Optimizer: `AdamW`
- LR scheduler: `constant with warmup`
- Warmup steps: `50`
- Epochs: `1`
- Batch size: shown as `See Below` in table (no explicit numeric replacement provided in text).
- Max grad norm: `1`
- Precision: `bfloat16 = True`
- Weight decay: `0`
- GRPO-only settings:
  - KL regularization coefficient: `0`
  - Group size: `64`
  - Prompts per generation: `8`
  - Num iterations (`mu`) sweep: `{1, 2}`
  - Loss: `Dr. GRPO (Liu et al., 2025)`

Note: The paper states some knobs (for example weight decay and max grad norm) were manually ablated and not included in the final sweep because they had no significant effect.

### B. Robotics experiments - OpenVLA-7B (SimplerEnv)

#### SFT
- Batch size sweep: `{16, 32, 64}`
- Learning rate sweep: `{1e-6, 3e-6, 5e-6, 7e-6, 9e-6, 1e-5, 3e-5}`
- Optimizer: `AdamW`
- Epochs: `1`
- Max grad norm: `1`
- Weight decay: `0`
- Warmup steps: `10`
- Scheduler: `constant with warmup`
- Precision: `bfloat16`

#### RL (REINFORCE)
- Uses the same training config as Robotics SFT above.
- Additional RL settings:
  - Reward-normalization baseline.
  - 5 trajectories per grid point each iteration.
  - Binary success reward.
  - Explicit KL regularization: none.

### C. MNIST experiments - 3-layer MLP
- Learning rate sweep: 15 values log-spaced between `3e-6` and `1e-3`.
- Scheduler options: `{constant with warmup, cosine with warmup}`.
- Epochs: `{1, 2}`.
- Reported run count: about 500 runs per method (including mid-training checkpoints).
- Method-specific setting:
  - GRPO + KL variant uses KL coefficient `0.1`.

### D. Scaling experiment (Science Q&A) - Qwen2.5 {3B, 7B, 14B}
- Reported setup: repeat SFT experiments from Section 3 on Science Q&A with 3B/7B/14B models.
- Additional distinct hyperparameter changes were not explicitly listed for this scaling section.

## 3) Quick mapping: dataset -> model -> training family
- Open-Reasoner-Zero (Math): `Qwen2.5 3B-Instruct`, SFT vs GRPO.
- SciKnowEval Chemistry L-3 (Science): `Qwen2.5 3B-Instruct`, SFT vs GRPO (plus objective-class comparisons in Section 5).
- ToolAlpaca (Tool Use): `Qwen2.5 3B-Instruct`, SFT vs GRPO.
- SimplerEnv Pick-and-Place (Robotics): `OpenVLA-7B`, SFT vs REINFORCE.
- ParityMNIST (with forgetting on FashionMNIST): 3-layer MLP, GRPO/GRPO+KL/SFT variants/oracle-SFT.
